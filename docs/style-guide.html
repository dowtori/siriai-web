03 — Spacing & Layout

8px 그리드 · 사치스러운 여백

모든 간격은 8의 배수. 섹션 사이는 96–128px로 크게 띄운다. "적게 담아 비싸 보이게."

--s-1 · 4
--s-2 · 8
--s-3 · 12
--s-4 · 16
--s-5 · 24
--s-6 · 32
--s-7 · 48
--s-8 · 64
--s-9 · 96
--s-10 · 128

레이아웃 규칙

· 콘텐츠 max-width 1200px, 본문 텍스트 블록은 680–760px로 더 좁게.

· 컬럼 좌우 여백(gutter) 32px 이상.

· 섹션 상하 패딩 96–128px. 모바일은 64–80px.

· 비대칭 그리드 허용 — 잡지처럼 텍스트와 이미지의 정렬을 일부러 어긋나게.

· 라운드는 작게(4–16px), 버튼만 pill. 과한 둥근 모서리는 감성을 깎는다.

radius: --r-sm 4 / --r-md 8 / --r-lg 16 / --r-pill 999

05 — Motion

조용한 모션 · 짧고 빠르게

화려함이 아니라 타이밍. 모든 모션은 ease-out(0.22,1,0.36,1), 200–480ms. 콘텐츠를 가리는 모션은 전부 삭제.

↑ 이 블록들은 스크롤 진입 시 아래에서 부드럽게 등장합니다.

translateY(24px) → 0 · opacity 0 → 1

stagger 60–80ms (줄/카드 단위)

스무스 스크롤은 Lenis(lerp≈0.1) + GSAP ScrollTrigger.

/* 모션 토큰 */
--ease: cubic-bezier(0.22,1,0.36,1);
--dur-fast: 200ms;  /* hover */
--dur:      300ms;  /* 기본 */
--dur-slow: 480ms;  /* reveal */

/* 권장 스택 */
Lenis + GSAP ScrollTrigger
SplitText → 줄 단위 stagger reveal
prefers-reduced-motion 존중(끄기)
주의: 느린 모션·과한 패럴랙스·자동재생 캐러셀 = 싸 보임. 시그니처 모션은 히어로 1곳에만.

06 — Design Tokens

복사해서 코드에 바로

아래 CSS 변수를 :root에 붙이면 이 페이지와 동일한 시스템이 됩니다. (동봉된 SIRIAI_design-tokens.css 파일과 동일)

/* SIRIAI design tokens — paste into :root */
--c-canvas:#F5F1EA;  --c-surface:#FFFFFF;  --c-surface-2:#EEE8DD;
--c-ink:#1C1A17;     --c-ink-soft:#4A443C; --c-muted:#857C70;
--c-line:#DCD4C6;    --c-accent:#C0532F;   --c-accent-soft:#E3C4B3;
--c-accent-ink:#8F3A1F; --c-dark:#1C1A17;  --c-dark-ink:#F2ECE1;

--f-serif:'Fraunces',Georgia,serif;
--f-sans:'Inter','Pretendard',system-ui,sans-serif;

--t-display:clamp(3.5rem,7vw,7rem); --t-h1:clamp(2.5rem,4.5vw,4rem);
--t-h2:2.5rem; --t-h3:1.75rem; --t-lg:1.25rem; --t-body:1.0625rem; --t-sm:.875rem;

--s-1:4px;--s-2:8px;--s-3:12px;--s-4:16px;--s-5:24px;
--s-6:32px;--s-7:48px;--s-8:64px;--s-9:96px;--s-10:128px;

--r-sm:4px; --r-md:8px; --r-lg:16px; --r-pill:999px;

--dur-fast:200ms; --dur:300ms; --dur-slow:480ms;
