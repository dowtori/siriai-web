# SIRIAI 홈페이지 — 레퍼런스 분석 리포트

> 대상: SIRIAI (글로벌 K뷰티·K팝 인플루언서 마케팅 / 브랜딩 전략 / 크리에이티브 제작 에이전시)
> 무드 방향: **미니멀·여백 + 감성·에디토리얼 + 인터랙티브·모션**의 교집합
> 목적: "감도 높은" 비주얼을 코드에 반영하기 위한 레퍼런스 해부 + 차용 포인트 정리

---

## 0. 한 줄 전략

SIRIAI는 "데이터로 굴러가는 마케팅 회사"인 동시에 "K뷰티·K컬처의 감성을 파는 회사"다.
따라서 홈페이지는 **에디토리얼한 잡지의 톤(감성·여백)** 위에 **딱 필요한 곳에만 모션(인터랙티브)** 을 얹어,
"세련됐지만 과하지 않은 = 프리미엄" 인상을 주는 것이 핵심이다. 화려함보다 **절제와 타이밍**이 고급감을 만든다.

---

## 1. 레퍼런스 클러스터 A — 미니멀 / 에디토리얼 (감성·여백)

이 그룹에서 훔칠 것: **여백의 사치, 세리프/산세리프 대비, 풀블리드 이미지, 절제된 컬러**

### Aesop — 에디토리얼 미니멀의 교과서 (뷰티 직접 연관)
- 거의 흑백에 가까운 절제: 따뜻한 오프화이트 배경(≈ `#F4F1EC`), 잉크 블랙 텍스트(≈ `#1A1A1A`).
- 세리프 본문 + 넉넉한 행간(line-height 1.6~1.8)으로 "읽는 경험"을 만든다. 마케팅 카피가 아니라 에세이처럼 보이게 함.
- 제품 사진은 채도를 죽이고 그림자를 부드럽게 — "약국 + 갤러리"의 인상.
- 시그니처: **과할 정도의 여백**. 콘텐츠 폭을 일부러 좁혀(680~760px) 한 화면에 적게 담는다.
- SIRIAI 차용: 캠페인 케이스를 "성과 숫자 나열"이 아니라 **에세이형 스토리**로 풀면 감성 + 신뢰가 동시에 선다.

### Linear — 미니멀 절제의 기준 (SaaS지만 디테일 참고)
- 거의 모노톤 + 한 가지 강조색. 다크/라이트 모두 회색 계조를 정교하게 사용.
- 타이포 위계가 전부: 헤드라인 크고 굵게(desktop 64~96px), 본문은 차분한 회색.
- 픽셀 단위의 정렬·간격 일관성. 8px 그리드를 절대 안 깬다.
- 시그니처: **디테일의 일관성**이 만드는 신뢰감. 미세한 보더(1px, 낮은 대비)와 절제된 그림자.
- SIRIAI 차용: 간격·정렬 시스템(8px 그리드)을 코드에 토큰으로 박아두면 "감도 약함"의 70%가 해결된다.

### Glossier 계열 — 소프트 에디토리얼 뷰티
- 따뜻한 파스텔 뉴트럴(더스티 로즈, 크림), 넓은 이미지 + 짧은 카피.
- 친근하지만 정돈된 — "프리미엄인데 다가가기 쉬움". K뷰티 타깃에 적합한 온도.
- SIRIAI 차용: 너무 차갑지 않게, **뉴트럴 베이스에 따뜻한 액센트 1개**(로즈/테라코타)를 더하면 뷰티 정체성이 산다.

### Locomotive — 크리에이티브 에이전시 에디토리얼 + 스크롤
- 큰 타이포 + 잡지식 비대칭 그리드, 스크롤에 따라 텍스트/이미지가 부드럽게 등장.
- 모션이 있지만 "조용하다" — 빠르고 짧은 이징, 화면을 어지럽히지 않음.
- SIRIAI 차용: **비대칭 그리드 + 부드러운 등장(reveal)** 조합이 에디토리얼 + 모션을 동시에 만족시키는 정답.

**클러스터 A 종합 — SIRIAI가 가져갈 것**
1. 따뜻한 오프화이트 베이스 + 잉크 블랙 + 따뜻한 액센트 1색의 절제된 팔레트.
2. 세리프(헤드라인) × 산세리프(본문) 대비로 에디토리얼 위계 구축.
3. 콘텐츠 폭을 일부러 좁히고 여백을 사치스럽게 — 적게 담아 비싸 보이게.

## 2. 레퍼런스 클러스터 B — 인터랙티브 / 모션

이 그룹에서 훔칠 것: **스크롤 연동 등장, 커서/호버 반응, 시네마틱 전환** — 단, 절제해서.

### Active Theory — 이머시브/WebGL의 최상단
- 풀스크린 비주얼, 마우스 따라 반응하는 3D/캔버스, 무거운 인터랙션.
- 배움: 모션이 "콘텐츠를 가리지 않는다". 진입 시 로딩 연출로 기대감을 설계.
- 주의: SIRIAI엔 이 정도 풀WebGL은 과함. **히어로 1곳에만** 시그니처 모션을 두는 게 맞다.

### Cuberto — 볼드 모션 에이전시
- 큰 타이포 + 강한 커스텀 커서 + 호버 시 요소가 살아 움직임.
- 컬러는 의외로 절제(화이트 베이스 + 강한 포인트 1색)해서, 모션이 튀어도 안 어지럽다.
- SIRIAI 차용: **커스텀 커서 + 호버 인터랙션**은 적은 비용으로 "감도"를 크게 올리는 가성비 좋은 기법.

### Framer (마케팅 사이트) — 슬릭한 현대적 모션
- 스크롤마다 섹션이 페이드/슬라이드로 등장, 마이크로 인터랙션이 매끄럽다.
- 모션 속도가 빠르고 짧다(200~400ms) — "기다리게" 하지 않는다.
- SIRIAI 차용: **짧고 빠른 이징(ease-out, 300ms 내외)** 을 전역 규칙으로. 느린 모션은 싸 보인다.

### Viral Nation — 인플루언서 마케팅 직접 경쟁 레퍼런스
- 동종 업계 톤: 강한 헤드라인 + 크리에이터/소셜 영상 썸네일 그리드 + 성과 지표.
- 배움: 업계 관행(케이스 그리드, 로고 월, 지표)을 따르되 **타이포와 여백으로 차별화**.
- SIRIAI 차용: 경쟁사가 "시끄럽게" 갈 때 SIRIAI는 **조용한 고급감**으로 가면 오히려 눈에 띈다.

**클러스터 B 종합 — SIRIAI가 가져갈 것 + 주의**
1. 시그니처 모션은 히어로 1곳 + 섹션 등장 reveal 정도로 제한. 전역 도배 금지.
2. 커스텀 커서·호버 마이크로 인터랙션으로 적은 비용에 감도 상승.
3. **주의**: 느리고 화려한 모션 = 싸구려. 짧고 빠르게(≤400ms), "콘텐츠를 가리는 모션"은 전부 삭제.

## 2.5. 실측 캡처 노트 (브라우저로 직접 확인)

아래는 실제로 사이트를 띄워 캡처해 확인한 내용 — 위 분석을 검증함.

- **Aesop (실측)**: 따뜻한 크림 오프화이트 배경 + 잉크 블랙. 세리프 로고/헤드라인 **중앙 정렬**, 1px 얇은 보더의 고스트 버튼("Discover Hand & Body" + → 화살표), 풀블리드 이미지가 하단에서 다크로 그라데이션. 위아래 여백이 한 화면을 거의 비울 만큼 넉넉함. → SIRIAI 히어로의 직접 모델로 적합.
- **Cuberto (실측)**: 순백 배경 + 블랙. 초대형 볼드 산세리프 헤드라인(체감 ≈110–120px) 중앙 정렬, 미니멀 내비(로고 좌 · 메뉴 우), 작은 커스텀 커서 도트. 모션이 강한 에이전시인데 **컬러는 흑백으로 절제** → 모션이 튀어도 안 어지럽다. SIRIAI도 "절제된 컬러 위 모션" 공식을 따를 것.
- **Viral Nation (실측, 경쟁사)**: 다크 배경 + 화이트 좌측 정렬 헤드라인 + **네온 핑크 액센트(≈#FF2D78)** + 크리에이터 영상 핸드폰 콜라주. 정보 밀도 높고 "시끄러운" 톤. → SIRIAI는 정반대(웜 뉴트럴·여백·조용한 모션)로 가야 같은 카테고리에서 오히려 차별화됨.
- **Linear (실측)**: 다크(near-black) 미니멀, **저대비 회색 내비** + 화이트 필(pill) CTA 버튼. 절제·정렬 규율의 기준. → SIRIAI는 라이트 베이스로 가되 이 "간격·정렬 규율"만 그대로 차용.

## 3. 2025–2026 트렌드 근거 (검증된 방향)

- **세리프×산세리프 페어링**이 뷰티/에디토리얼의 표준: 헤드라인 세리프(Playfair Display / Freight Text 류) + 본문 산세리프(Inter / Source Sans 류)로 위계와 고급감.
- **풀블리드 이미지 + 뮤트 럭셔리 팔레트**(웜 뉴트럴·세이지·더스티 로즈)가 채도 높은 색을 대체 — 프리미엄 신호.
- 히어로 타이포가 **80px 이상**(데스크톱), 종종 120px+ 까지 커지는 추세.
- 스크롤 모션은 **GSAP ScrollTrigger + Lenis(스무스 스크롤)** 조합이 사실상 표준. 텍스트는 줄 단위 스태거 reveal.
- 최상위 에이전시 사이트의 공통점: **홈 로딩 3초 이내 + 첫 화면에 CTA**, 케이스는 개요→과정→성과(지표) 3단 구성.

---

## 4. SIRIAI 적용 우선순위 (감도 약함 → 강함, 가성비 순)

1. **간격·타이포 토큰화** (8px 그리드, 타입 스케일) — 비용 낮고 효과 큼. 1순위.
2. **세리프×산세리프 페어링 + 큰 히어로 타이포** — 즉각적인 에디토리얼 인상.
3. **웜 뉴트럴 팔레트 + 액센트 1색** — 일관된 무드.
4. **섹션 등장 reveal (Lenis + ScrollTrigger)** — 조용한 모션.
5. **커스텀 커서 + 호버 마이크로 인터랙션** — 디테일의 감도.
6. **히어로 시그니처 모션 1개** — 여력 있을 때 마지막에.
